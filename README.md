# Graduation Invitation — Phương Mai

Thiệp mời tốt nghiệp dạng website, thiết kế theo phong cách sang trọng, nữ tính với tông hồng phấn, đỏ rượu và ánh vàng.

## Xem bản thiệp

Mở file `index.html` bằng Chrome/Edge. Không cần cài đặt hay build.

Trang hỗ trợ đường dẫn cá nhân hóa tên khách mời. Sau khi đăng lên web, thêm `?to=Tên khách` vào cuối link, ví dụ:

```text
https://ten-cua-ban.github.io/graduation-invitation/?to=Minh%20Anh
```

Thêm `&open=1` nếu muốn bỏ qua màn mở thiệp:

```text
https://ten-cua-ban.github.io/graduation-invitation/?to=Minh%20Anh&open=1
```

## Chỉnh nội dung

- Tên, niên khóa, trường và lời mời: tìm `Phương Mai`, `2022 — 2026` hoặc `Foreign Trade University` trong `index.html`.
- Màu sắc và bố cục: chỉnh các biến màu ở đầu `styles.css`.
- Cách chia sẻ, cá nhân hóa tên khách và hiệu ứng: nằm trong `script.js`.
- Ảnh đã được tối ưu thành hai kích thước 960 px và 1600 px trong thư mục `assets/`; ảnh gốc không bị thay đổi.

## Đăng lên GitHub Pages

1. Chép toàn bộ nội dung thư mục này vào repo GitHub.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)`.
4. Chờ GitHub tạo đường dẫn và dùng nút **Chia sẻ thiệp** trên trang.
